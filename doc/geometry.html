The geometry library

The geometry library has functions and types for 2-dimensional and 3-dimensional vector spaces.

The Geom2 and Geom3 index sets define the space's coordinates.

For the Geom2 space vectors and matrices can be constructed with functions vector2d and matrix2d.

For the Geom3 space vectors and matrices can be constructed with functions vector3d and matrix3d.

Base vectors are also available. Values basis2d and basis3d are tuples containing the vectors. They can be used like

let (ex, ey) = basis2d in
    ...
end

Index sets

Geom2

Index set for a 2D geometric space. Defined as the set {x, y}.

Geom3

Index set for a 3D geometric space. Defined as the set {x, y, z}.

perpendicular

:: for_unit a: (a*Geom3!, a*Geom3!) -> a*Geom3!

Vector perpendicular to two given vectors. The given vectors and the result come from the same space, and the result vector scales proportionally when the space unit changes.

This function is the 'square root' of the cross product. It is not a product like the cross function. It lacks distribution over addition, associativity and the Jacobi identity. Sometime however, you just want a perpendicular vector in the same space.

Defined as

cross(v,w) '/.' sqrt(norm(v) * norm(w))

Some properties

Let p = perpendicular(v, w)

The norm |p| satisfies

|p|^2 = sin(a)^2|v||w|

where a is the angle between v and w.

Furthermore:

  • p = v x w for dimensionless unit vectors
  • vector p is zero when v = w
  • |p|^2 = |v||w| when v and w are orthogonal
  • |p| = sin(a)|v| = sin(a)|w| when |v| = |w|
  • |p| = |v| = |w| when v and w are orthogonal and |v| = |w|

Example

Say v = (3m 0m 0m) and w = (0m 3m 0m) then perpendicular(v, w) is (0m 0m 3m), whereas cross(v, w) is (0m 0m 9m^2)

to_polar2d

:: for_unit a: (a*Geom2!) -> Tuple(a, radian)

Gives polar coordinates for a vector in cartesian coordinates. A tuple with the norm and the angle.

For any vector v the following equality holds

let (nrm, ang) = to_polar2d(v) in to_cartesian2d(nrm, ang) end = v

to_polar3d

:: for_unit a: (a*Geom3!) -> Tuple(a, radian, radian)

Gives polar coordinates for a vector in cartesian coordinates. A tuple with the norm, the inclination and the azimuth.

For any vector v the following equality holds

let (nrm, inc, azi) = to_polar3d(v) in to_cartesian3d(nrm, inc, azi) end = v

values2d

:: for_unit a: (a*Geom2!) -> Tuple(a, a)

The vector's values as a tuple. The opposite of vector2d

For example

let (x, y) = values2d(vector2d(3, 4)) in ... end

binds x to 3 and y to 4.

values3d

:: for_unit a: (a*Geom3!) -> Tuple(a, a, a)

The vector's values as a tuple. The opposite of vector3d

For example

let (x, y, z) = values3d(vector3d(3, 4, 5)) in ... end

binds x to 3, y to 4 and z to 5.
